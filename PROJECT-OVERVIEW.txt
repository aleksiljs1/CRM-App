==============================================================================
KRESTON CRM — PROJECT OVERVIEW
==============================================================================


WHAT IT IS
------------------------------------------------------------------------------
An internal CRM and workspace built for Kreston Albania, an accounting / audit
/ tax / advisory firm. It is a multi-department, role-based business
application used by firm staff (with a small portal view for clients).


WHAT IT DOES
------------------------------------------------------------------------------
A single platform that runs the firm's operational work end-to-end:

  - Role-based, department-isolated dashboards.
    Admin, Partner, Manager, and per-department views (Audit, Legal, Tax,
    Payroll, Advisory, HR, Marketing, Finance). Each user sees only what
    their role + department allows.

  - Email hub.
    Incoming / outgoing email with AI prioritization (Google Gemini), live
    IMAP inbox polling, threaded view, reply with file attachments.

  - Tasks (Kanban).
    Workflow: TODO -> IN_PROGRESS -> REVIEW -> APPROVED -> COMPLETED.
    Priorities (LOW / MEDIUM / HIGH / URGENT), assignees, deadlines,
    attachments, full status history, Trello-style team comments,
    and a "describe the work you did" prompt when a worker progresses a card.

  - Clients & pipeline.
    LEAD / ACTIVE / INACTIVE pipeline with assigned firm contacts.

  - Document submissions & AI validation.
    Clients submit documents against process templates (e.g. an "Annual
    Audit" requires Financial Statements, Trial Balance, etc.). Gemini
    matches the uploaded files to the required documents.

  - Performance tracking.
    Per-employee performance score (0-100) calculated from completion rate,
    on-time rate, high-priority handling, response / cycle time, and
    revisions. Animated gauge, ranking strip, and an AI Career Coach that
    surfaces strengths / growth areas / next goal.

  - Real-time chat.
    1-to-1 and group chat with file attachments, typing indicators, unread
    counts. Powered by Socket.io.

  - Notifications.
    Top-bar bell with live push (Socket.io) for new emails, tasks, comments,
    and status changes.

  - Team & department management.
    Managers can add employees, see workload by department, and set
    department auto-assign rules.

  - Dark mode.
    Full light / dark theme across every page, persisted per user, respects
    OS preference, no flash on load.

  - Role-colored sidebar.
    Each role gets a subtle background wash (slate, indigo, blue, emerald,
    cyan, amber, orange, pink, brand-teal) so it is obvious at a glance who
    is logged in.


TECH STACK
------------------------------------------------------------------------------
  Language          TypeScript 5  (everything — frontend and backend)
  Framework         Next.js 16    (App Router, React Server Components)
  UI runtime        React 19
  Styling           Tailwind CSS v4 (CSS-first, no tailwind.config.js)
  Components        shadcn/ui v4 (style "base-nova") on @base-ui/react
                    (Base UI, not Radix)
  Icons             lucide-react
  Charts            Recharts (bar, pie, area / line)
  Toasts            sonner
  Auth              NextAuth v4 (credentials provider, JWT sessions,
                    bcryptjs for password hashing)
  Database / ORM    PostgreSQL  +  Prisma 7
  AI                Google Gemini (@google/generative-ai) — email
                    prioritization, performance coach, document matching
  Email             nodemailer (SMTP send) + imap-simple + mailparser
                    (inbox polling)
  Real-time         Socket.io  (chat + notifications)  running on a custom
                    Node server (server.ts, executed via tsx) instead of
                    plain `next dev`
  File handling     pdf-parse  (extract text from PDF submissions for AI
                    document matching)


LANGUAGES SUMMARY
------------------------------------------------------------------------------
Everything is written in TypeScript — the React UI, the API routes, the
Prisma schema, the custom Node server, the seed scripts.

  - CSS is handled through Tailwind v4 with custom CSS variables in
    src/app/globals.css.
  - SQL is generated by Prisma against PostgreSQL (running in a Docker
    container locally).
  - HTML is server-rendered by Next.js.
  - JSON is the wire format for the API.

In short:  one language end-to-end (TypeScript),
           a single React + Next.js codebase,
           a Postgres database accessed only through Prisma,
           a real-time layer via Socket.io.
