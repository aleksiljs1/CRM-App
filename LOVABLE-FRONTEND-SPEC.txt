1. WHAT THE APP IS
------------------------------------------------------------------------------
"Kreston CRM" — an internal CRM / workspace for Kreston Albania, an accounting,
audit, tax and advisory firm. It is a multi-department, role-based business app
used by firm staff (not the public).

Core features:
  - Role-based, department-isolated dashboards
  - Email hub with AI prioritization (Google Gemini) + IMAP inbox polling
  - Task management (Kanban board with a TODO -> COMPLETED workflow)
  - Client management + client pipeline (LEAD / ACTIVE / INACTIVE)
  - Client document submission & AI validation
  - Performance tracking with AI review + team performance
  - Team management

Brand: name "Kreston CRM", brand color TEAL #00968a, logo is a teal tile with
a white bold letter "K".

11. SCREEN-BY-SCREEN SUMMARY (what each app page shows)
------------------------------------------------------------------------------
Overview dashboard (/dashboard/hr): 4 stat cards (Unread Emails, Total Clients,
  Pending Tasks, Open Processes) + a "Recent Unread Emails" list + quick action
  buttons. Title shows the user's department.

Emails (/dashboard/hr/emails): two-pane inbox. Left = paginated email list with
  filters (all / unread / read / unreplied / replied) + search. Right = email
  thread reading pane with reply box + file attachments. "Order by Important"
  triggers AI (Gemini) prioritization. Polls inbox every 10s.

Tasks (/dashboard/hr/tasks): Kanban board, 5 columns (To Do, In Progress,
  Review, Approved, Completed) + overdue indicator. Task cards show priority
  badge, client, department, deadline, assignee. Task detail modal with a
  workflow progress bar + status history. "New Task" form.

Documents (/dashboard/hr/documents): document library / client submissions.

My Performance (/dashboard/hr/performance): personal performance score (0-100),
  rank vs other employees, leaderboard strip, score breakdown bars, AI coaching
  tips, role/department tags.

Manager dashboard (/dashboard/manager): team KPI cards, charts (tasks by
  department, client pipeline), department workload, upcoming deadlines,
  recent activity.

Client Pipeline (/dashboard/manager/clients): Kanban of clients grouped by
  ClientStatus (LEAD / ACTIVE / INACTIVE), client cards, search, summary cards.

Team Performance (/dashboard/manager/performance): team-wide performance, AI
  executive summary, per-member scores, raise recommendations.

My Team (/dashboard/manager/team): list/manage team members.

Admin (/dashboard/admin): admin settings / user management.
Partner (/dashboard/partner): firm-wide partner overview.
Client (/dashboard/client): external client portal view (submissions, docs,
  messages).
Clients (/dashboard/clients): clients list.
Reports (/dashboard/reports): reporting / analytics.
